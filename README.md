# «Ход конём» — установщики

Здесь лежат файлы программы «Ход конём» (шахматный клуб имени Алехина при Лицее №1 «Лидер»):
для Windows и Android, в двух редакциях — «Полная» и «Офлайн». Бесплатно, без рекламы.

**Как установить — с картинками:** https://hodkonem-chess.vercel.app/#/install

Скачивайте файлы со страницы «Выпуски» (Releases) справа. Контрольные суммы SHA-256 — на странице установки.
Исходный код шахматного движка Stockfish (GPL-3.0): https://github.com/official-stockfish/Stockfish
